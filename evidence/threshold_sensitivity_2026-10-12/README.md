# THLB-threshold sensitivity (2026-10-12), TSA41

Question: does the landbase rule change the campaign results? The campaign keeps stands whose mean THLB signal is at least 50, at full stand area. This evidence reruns the same configuration with thresholds 25 and 75.

Configuration (all variants): even-flow epsilon 0.10; maximize totvol x 0.85; 200-year horizon, 10-year periods (20 periods); clearcut operable 80-400 years; initial-age cap 300 with 10-year snapping; regeneration to age 0; landbase = stands with mean THLB signal >= threshold, at full stand area.

Points per threshold: nadir (maximum harvest); maximum-bird endpoint (objective = bird abundance, harvest even-flow); cbird0.50 (per-period bird floors halfway between the nadir and maximum-bird series).

Files: tsa41-thlbNN-{nadir,bmax,cbird0.50}.csv (NN = 25, 50, 75) and threshold_sensitivity_2026-10-12.md (all five TSAs).

Provenance: engine wbi-birds b4f62a0 (pinned copy; the campaign was run on this engine source). femic code unchanged since 00da95d (threshold option). Scratch runs only; no published instance output was overwritten.

Control: threshold-50 rows regenerated by the same pipeline match the published campaign CSVs (maximum relative difference 3.09e-13).

Numerical note: at threshold 25 the solve logged two warnings for residual areas of about -1.8e-10 ha in one dtype (cc actions). All solves are optimal; the effect is negligible.
